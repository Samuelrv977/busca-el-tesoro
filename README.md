# 🏴‍☠️ BUSCA EL TESORO
Descripción general

Busca el Tesoro es un videojuego interactivo de aventura y exploración en el que el jugador deberá encontrar un tesoro escondido mediante la resolución de pistas y la exploración de diferentes islas.

El jugador asumirá el papel de un explorador que deberá interpretar las pistas, seleccionar ubicaciones en un mapa y superar diferentes etapas hasta encontrar el tesoro.
Objetivo del proyecto

Desarrollar un videojuego interactivo que combine entretenimiento, exploración y razonamiento lógico, permitiendo que los jugadores resuelvan pistas y encuentren un tesoro escondido.
