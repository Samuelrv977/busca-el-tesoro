# Busca el tesoro

Videojuego interactivo de aventura y búsqueda de tesoros. Explora la isla,
sigue la brújula y encuentra el cofre escondido.

## Cómo jugar

Abre `index.html` en un navegador. Usa las flechas del teclado, WASD o los
controles en pantalla para moverte. El diario indica si te acercas al tesoro;
«Nueva aventura» reinicia la expedición con un nuevo escondite.
