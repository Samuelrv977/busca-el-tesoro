# Historias de usuario – Busca el Tesoro

Las historias de usuario describen las funcionalidades del videojuego desde el punto de vista del jugador, indicando qué necesita realizar y cuál es el beneficio que obtiene.

## HU01. Iniciar el juego
**Como** jugador,  
**quiero** iniciar una nueva partida,  
**para** comenzar mi aventura en busca del tesoro.

## HU02. Seleccionar dificultad
**Como** jugador,  
**quiero** seleccionar entre diferentes niveles de dificultad,  
**para** elegir el reto que mejor se adapte a mis habilidades.

## HU03. Visualizar el mapa
**Como** jugador,  
**quiero** visualizar un mapa con diferentes islas y ubicaciones,  
**para** explorar los lugares donde podría estar escondido el tesoro.

## HU04. Recibir pistas
**Como** jugador,  
**quiero** recibir pistas durante la aventura,  
**para** descubrir dónde se encuentra el tesoro.

## HU05. Seleccionar una ubicación
**Como** jugador,  
**quiero** seleccionar una ubicación del mapa,  
**para** comprobar si encontré el lugar correcto.

## HU06. Conocer el resultado
**Como** jugador,  
**quiero** recibir un mensaje cuando gane o pierda la partida,  
**para** conocer el resultado de mi aventura.
