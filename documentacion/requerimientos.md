# Requerimientos del sistema

## 1. Requerimientos funcionales

**RF01. Iniciar juego:** El sistema debe permitir al jugador iniciar una nueva partida.

**RF02. Seleccionar dificultad:** El sistema debe permitir elegir entre tres niveles de dificultad: fácil, medio y difícil.

**RF03. Mostrar mapa:** El sistema debe presentar un mapa interactivo con diferentes islas y ubicaciones para explorar.

**RF04. Presentar pistas:** El sistema debe proporcionar pistas que ayuden al jugador a encontrar el tesoro escondido.

**RF05. Verificar respuestas:** El sistema debe comprobar si la ubicación seleccionada por el jugador es correcta o incorrecta y descontar una vida si se equivoca.

**RF06. Finalizar partida:** El sistema debe mostrar un mensaje de victoria cuando el jugador encuentre el tesoro o de derrota cuando pierda todas sus vidas.

## 2. Requerimientos no funcionales

**RNF01. Usabilidad:** El videojuego debe contar con una interfaz sencilla, clara e intuitiva.

**RNF02. Rendimiento:** El sistema debe responder rápidamente a las acciones realizadas por el jugador.

**RNF03. Compatibilidad:** El videojuego debe funcionar correctamente en los navegadores web modernos.

**RNF04. Seguridad:** El sistema debe proteger la información y evitar modificaciones no autorizadas.

**RNF05. Mantenibilidad:** El código debe estar organizado para facilitar futuras modificaciones y mejoras.

**RNF06. Diseño:** El videojuego debe contar con gráficos, colores e imágenes atractivas relacionadas con la temática de aventuras y búsqueda de tesoros.
