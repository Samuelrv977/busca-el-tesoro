# Componentes técnicos – Busca el Tesoro

## 1. Tecnologías de desarrollo

Para el desarrollo del videojuego Busca el Tesoro se proponen las siguientes tecnologías:

### HTML5
Se utilizará para crear la estructura del videojuego, organizar las pantallas, botones, textos y elementos visuales.

### CSS3
Se encargará del diseño y la apariencia del videojuego, incluyendo colores, fondos, estilos, animaciones y distribución de los elementos.

### JavaScript
Permitirá desarrollar la lógica del videojuego, controlar las vidas, gestionar las pistas, verificar las respuestas y manejar el avance entre etapas.

### GitHub
Se utilizará para almacenar el código fuente, organizar la documentación y llevar el control de las modificaciones del proyecto.

## 2. Componentes principales del sistema

**Interfaz gráfica:** permite al jugador interactuar con los elementos del videojuego.

**Mapa interactivo:** representa las islas y ubicaciones que el jugador puede explorar.

**Sistema de pistas:** proporciona información para orientar al jugador durante la búsqueda.

**Sistema de vidas:** controla las oportunidades disponibles y descuenta vidas cuando el jugador se equivoca.

**Sistema de dificultad:** permite seleccionar entre los niveles fácil, medio y difícil.

**Sistema de resultados:** determina si el jugador ganó o perdió la partida.

## 3. Entorno de ejecución

El videojuego estará diseñado para ejecutarse en navegadores web modernos, permitiendo que los usuarios puedan acceder desde un computador con conexión a internet o mediante los archivos del proyecto.

## 4. Almacenamiento de información

Se propone utilizar LocalStorage de JavaScript para guardar información local del jugador, como el progreso y las puntuaciones, si estas funcionalidades se implementan.

## 5. Herramientas de apoyo

- Visual Studio Code: edición y desarrollo del código.
- GitHub: almacenamiento y control de versiones.
- Navegador web: pruebas y ejecución del videojuego.
